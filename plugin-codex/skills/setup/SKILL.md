Set up Archivist in the current project. Resolve this plugin root from this skill file. Run `node "<plugin-root>/bin/archivist" init`, then `node "<plugin-root>/bin/archivist" doctor`. Explain that lifecycle hooks must be enabled and trusted in Codex. Start a new chat and run collection to verify SessionStart delivery. Knowledge lives in .archivist; generated procedures live in .agents/skills. No separate API key is needed. No background model calls are made.
