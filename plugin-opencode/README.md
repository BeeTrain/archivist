# Archivist для OpenCode

Плагин для **OpenCode 2.2.5 (V2)**. Использует общую базу `.archivist/` с версиями для Claude Code и Codex. Нужен Node.js ≥ 20 в PATH сервера OpenCode.

## Подключение из исходников

В корне репозитория Archivist:

```bash
npm ci
npm run build
npm run validate:opencode
```

В `opencode.jsonc` своего проекта добавь путь к этому каталогу, сохранив остальные настройки:

```json
{
  "plugins": ["/absolute/path/to/archivist/plugin-opencode"]
}
```

В самом репозитории Archivist это уже настроено через `opencode.jsonc`: при открытии проекта загружается собранный пакет из `plugin-opencode/`.

Затем открой проект в OpenCode и вызови `/archivist init`, `/archivist status`. Плагин добавляет инструмент `archivist` и навыки `archivist-recall`, `archivist-remember`, `archivist-decide`, `archivist-triage`. Результат slash-команды добавляется в очередь сессии без запуска модели; агент получает его при следующем продолжении. Через инструмент результат возвращается сразу.

Для всех проектов тот же путь можно добавить в `~/.config/opencode/opencode.jsonc`. Пакет пока не опубликован в npm. V1 не поддерживается.

## Интерфейс OpenCode Desktop

Над полем ввода появляется индикатор: количество записей, очередь ревью и состояние анализа. По нажатию открывается панель с поиском, предложениями и последним отчётом. Панель также доступна через `/archivist-panel` и меню добавления боковых вкладок. В очереди можно принять или отклонить отдельное предложение; решения и удаления отмечены явно. После анализа появляется короткое уведомление. Отображение данных не вызывает модель.

Desktop загружает визуальные части из плагинов своего фонового сервера. Если Архивист установлен только для проекта, добавь в `plugins` глобального `~/.config/opencode/opencode.jsonc` путь к **подкаталогу `ui/`** установленного плагина:

```json
{
  "plugins": ["/absolute/path/to/project/.opencode/plugins/archivist/ui"]
}
```

Этот вспомогательный пакет содержит только интерфейс: сбор и анализ остаются включены лишь в проектах, где установлен основной плагин. Если основной пакет уже подключён глобально, дополнительная запись `ui/` не нужна.

Интерфейс обновляется каждые две секунды, читая базу текущего проекта; результат держится до следующего запроса, последний отчёт остаётся доступен в панели. При переключении проекта прежние данные скрываются. GUI API экспериментальный; сборка и проверка рассчитаны на OpenCode Desktop 2.2.5.

## Что работает

- Перед запросом модели подставляются общие знания и ограниченная подборка правил для затронутых файлов.
- Сохраняются очищенные запросы, тексты ответов, цели инструментов, краткие ошибки и метрики. Содержимое прочитанных файлов, патчи и рассуждения модели не собираются.
- Через 90 секунд после завершения работы запускается отдельный анализ без инструментов и записей в историю чата. По умолчанию используется модель сессии; все изменения направляются на ревью.
- Новый запрос отменяет ожидание и устаревший анализ. Очередь, дедупликация и дневные лимиты сохраняются на диске; после перезапуска обработка продолжается, когда сервер загрузит проект.
- Сбор ограничен основной сессией текущего каталога. Подагенты и сессии других проектов не смешиваются.

Настройки находятся в общей `.archivist/config.json`:

```json
{
  "opencode": {
    "enabled": true,
    "model": "",
    "timeoutSeconds": 120,
    "maxCallsPerDay": 20
  }
}
```

Для отдельной модели укажи `provider/model`. `analyzer.idleSeconds` и `analyzer.maxTokensPerDay` задают паузу и дневной бюджет. API генерации 2.2.5 возвращает только текст: расход токенов оценивается по длине текста, жёстко ограничивается число вызовов. Вызовы используют настроенного провайдера OpenCode и расходуют его лимиты или оплачиваются по его тарифу.

Команды: `/archivist recall <запрос>`, `/archivist review`, `/archivist apply <id>`, `/archivist skip <id>`, `/archivist analysis status|enable|disable`. Полный набор ручных команд доступен через `node /absolute/path/to/plugin-opencode/bin/archivist help`; `panel` запускается отдельно из терминала.

Правила пишутся в `.archivist/opencode/rules/`, процедуры — в `.opencode/skills/`. Временные данные лежат в `.archivist/.local/opencode/`, автоматически исключённом из git. Файлы Claude Code и Codex не изменяются.

Удаление: `node /absolute/path/to/plugin-opencode/bin/archivist uninstall`, затем убери путь плагина из настроек OpenCode. `--purge` удаляет общую базу всех платформ.
