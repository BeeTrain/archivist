---
name: archivist-remember
description: "Save an exact command or non-obvious project pitfall when the user asks to remember it"
---

Use the archivist tool with command `add --type command|gotcha --title "..." --content "..." [--paths "glob"] [--evidence "file"]`. Save the durable fact, not session history. Check recall first and edit an existing entry if it already covers the fact. Never include credentials or session identifiers.
